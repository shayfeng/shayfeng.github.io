# shayfeng.github.io

一个可直接发布到 GitHub Pages 的个人网站静态版本。

## 当前内容来源

本页面已经根据 `参考资料/` 中的材料进行了整理和改写，主要使用了：

- `个人简历-冯紫嫣Shay.pdf`
- `作品集-冯紫嫣Shay.pdf`
- `Ziyan+FENG_progress.pptx`

并从中提取了头像、项目配图与主要经历信息。

## 目录说明

- `index.html`：页面结构与文案
- `assets/styles.css`：样式与响应式布局
- `assets/script.js`：页脚年份脚本
- `assets/images/`：站点用图
- `参考资料/`：原始简历、作品集和进展材料
- `tmp/`：中间提取与预览文件

## 发布到 GitHub Pages

1. 创建仓库 `shayfeng.github.io`
2. 将 `mypage/` 目录下的网站文件放到仓库根目录
3. 提交并推送到 `main` 分支
4. 等待 GitHub Pages 发布后访问 `https://shayfeng.github.io`

用户主页仓库会按仓库根目录直接发布。
